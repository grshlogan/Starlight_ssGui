# 运行手册与事故复盘 — 目录规则

本目录记录**已验证**的操作步骤、恢复入口与事故事实。运行手册不授予执行权限;实际命令、环境与授权仍以根规则、任务包和工程验证策略为准。

## 规则

1. 每份手册写明:触发条件、前置条件/权限、步骤、预期结果、回退或恢复、负责人与最近验证日期;命令必须来自真实配置或已执行证据。
2. 不写凭据、私网端点、生产数据与本机绝对路径;指代受控配置时只写获取方式与脱敏路径。
3. 复盘分开记录:影响、时间线、已验证事实、仍为 `hypothesis` 的根因、纠正动作、未覆盖范围;未确认根因不得写成事实。
4. 恢复结果绑定精确版本、平台、数据集、命令与真实退出码;演练或兼容层结果不能关闭原生平台门。
5. 不复制第二份配置/依赖/验证清单;回链真实配置、[工程验证策略](../engineering/AGENTS.md) 与任务/证据。
