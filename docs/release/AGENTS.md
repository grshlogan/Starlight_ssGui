# 发布记录 — 目录规则

本目录存放发布记录:每个版本一个 `v<version>.md` 与发布前检查清单。发布需任务包授权且验证门关闭;本文件定义记录结构与纪律,随目录常驻。

## 规则

1. **只写有证据的用户可见变化**:有代码、构建或真实运行证据支撑的行为;内部重构、调试探针与未验证推断不得写成已交付能力。如实写明未决问题与覆盖限制。
2. **一版一文件,命名 `v<version>.md`**:已发布版本永不覆盖;勘误写在后续版本或带日期的勘误段。
3. **发布事实唯一**:维护外部 `CHANGELOG.md` 时与其保持一致;根 `README.md`/`CHANGELOG.md` 由所有者决定是否维护,本目录不代写。
4. **引用前先读源**:Issue/PR 需读标题、正文与状态后才可挂到条目上;不得凭编号猜测或复用旧版链接。
5. **发布门**:[阶段路线图](../plan/AGENTS.md) 的阶段门由验收人关闭;[工程验证策略](../engineering/AGENTS.md) 的入口通过;未覆盖范围如实记录。

## 发布前检查清单(每版逐项)

- [ ] 版本号与基线提交/SHA 一致;构建产物可复现且不含机密。
- [ ] 全部验证入口已运行;退出码与证据已归档。
- [ ] 条目只覆盖已验证范围;未决问题已列出。
- [ ] 维护 `CHANGELOG.md` 时已同步。
- [ ] 历史版本文件未改动。
