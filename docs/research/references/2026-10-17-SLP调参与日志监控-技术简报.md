# Topaz Video SLP 调参 + 日志监控 — 技术文档

> 版本 v1.0 · 2026-10-17 · 面向 Rust + pocketjs 实现
> 归档说明:归档进 Starlight_ssGui 时已脱敏(绝对路径 → 别名/项目相对路径);原始工作副本不复存。
> 目标程序:Topaz Video 1.7.x(本机 1.7.2,Windows x64)
> 范围:**只做 ①调参注入 ②日志监控**。不做转码链/分段/插帧/安装器。

---

## 1. 调用链与总体架构

```
Topaz Video.exe (Qt6 GUI)
   └─ 生成 neuroserver 命令行 ──> neuroserver.exe (内置 Python 3.12 + torch 2.7+cu128)
         └─ 加载 SLP 模型模块 (models.slp25.<hash>.pyd)   ← 调参注入点
         └─ stdout 输出进度 JSON                          ← 监控数据源(之一)
Topaz 主日志 (%APPDATA%\...\logs\*-Main.tzlog)           ← 监控数据源(之二)
```

- 星光 2.6 的权重以 `slp-2.5.json` 清单分发(`slp26.zip` → `models.models/slp-2.5/20260731.0/`)。
- Neuroserver 模型根目录(Topaz 1.7.2 实测):`<TOPAZ_MODEL_STORE>`(权重在 `models\models\<家族>\blob.*`)。
- 参数注入**不改任何安装文件**,全部发生在 neuroserver 子进程内存中,进程退出即失效。

## 2. 调参注入机制(核心)

### 2.1 原理

1. 启动 Topaz 时给**子进程**注入环境变量 `PYTHONPATH=<hook目录>`;
2. neuroserver 的 Python 启动时自动 `import sitecustomize`(CPython 内置行为,无需改 Topaz);
3. hook 拦截 `models.slp25.*` 模块的导入(`ExtensionFileLoader.exec_module` 包装 或 meta-path 钩子);
4. 做**契约校验**(模块里必须有 `PIX_CHUNK_SIZE`、`VAE_DECODE_TILE_SIZE` 等属性,防止打错模块);
5. `setattr(module, attr, value)` 改模块全局变量;深补丁则包装模块/类方法;
6. 全程 try/except 失败安全:任何异常只写审计日志,不影响原生运行。

最小可用实现约 80 行 Python(即开源快照 `learn/sources/github.com/LoveRain1997/TopazStarlightUI/v5.9/slptune/sitecustomize.py`);工业级实现 1200~1600 行(含校验/审计/cuDNN/回滚,参考见 §5)。

### 2.3 目标模块发现

模块名形如 `models.slp25.<随机hash>`(编译 .pyd),每代 Topaz 会变:

| Topaz 版本 | 已知模块名 |
|---|---|
| 1.7.0 | `models.slp25.m0vm5nn8kicb` |
| 1.7.1 | `models.slp25.rx095brph7m1` |
| 1.7.2 | **未知,需动态发现**(本机尚未跑过 SLP 渲染) |

两种策略:

- **A. 契约匹配(简单,开源快照方式)**:钩住所有 `name.startswith("models.slp2")` 的模块导入,校验存在 `PIX_CHUNK_SIZE`/`VAE_DECODE_TILE_SIZE` 属性后注入。换版本零维护。
- **B. 文件扫描+哈希(严谨,skv89 方式)**:启动前扫描 neuroserver 的 models 目录找候选 `.pyd`,算 SHA256,通过 `TOPAZ_SLP_TARGET_MODULE_*` 环境变量传入,hook 内二次校验,不匹配就拒绝注入(防打错模块)。

### 2.4 进阶深层补丁(Lite 版实现,值得参考)

- 注意力后端强制:包装 `models.slp25.*` 下所有含 `attention_mode` 参数的类(sdpa/flash/sage,注意 Cython 扩展类不能逐方法 patch,只能包类绑定);
- VAE 深补丁:替换 `models.slp25.src.models.video_vae_v3` 模块的 `set_causal_slicing`(强制因果切分大小)与 `cl_decode`(channels_last);
- full pool:包装 full-pool 构造器强制开启。

### 2.5 审计输出(监控的第一手数据)

Lite 的 hook 每做一次变更就写一条 JSON:

```json
{"timestamp_utc":"...","pid":1234,"launch_id":"...","event":"apply","changes":{...}}
```
- 文件:`TOPAZ_SLP_OVERRIDE_AUDIT_FILE` 指向的 JSONL;
- 同时打印到 stderr,前缀 `[SLP Lite]` / `[Topaz SLP override]`;
- 用途:**验证"GUI 里设的参数"与"实际生效的参数"是否一致**——这是调参工具最有价值的自证功能。

### 2.6 cuDNN 预载(可选增强)

- 通过 manifest 在 torch 导入前把指定 cuDNN DLL 预载进进程(含 `glob` 重定向与 SHA 校验);
- 社区实测:cuDNN **9.24.0.43 (cu12)** 对 Topaz CUDA 12.8 运行时约 **+32.8%** 吞吐(24GB+ 卡同样有效,且不需要改 SLP 参数)。

## 3. 启动路径

### 3.1 GUI 路径(推荐)

Rust 侧只做三件事:
1. 组装环境变量(上表)后 `CreateProcess` 启动 `Topaz Video.exe`;
2. 用户在 GUI 里正常导出;
3. 监控线程 tail 日志目录 + 审计 JSONL。

优点:完全复刻官方行为(下载/队列/预览都正常);hook 天然作用于 Topaz 拉起的 neuroserver 子进程。

### 3.2 CLI 路径(开源快照 topaz_ui.py 的路线)

自己拼 `neuroserver.exe --once ...`(参数见附录 A),直接读 stdout 进度 JSON。
优点:不依赖 GUI 自动化;缺点:非官方路径,版本升级易碎。

## 4. 日志监控

### 4.1 文件与格式

- 目录:`%APPDATA%\Topaz Labs LLC\Topaz Video\logs\`
- 文件名:`YYYY-MM-DD-HH-MM-SS-Main.tzlog`(本机 1.7.2 实测仍为 `.tzlog`;launchers 还兼容 1.7.1+ 的 `.log` 变体,实现时两种都扫)
- 行格式(实测):

```
2026-10-17 12-20-03.721 Thread: 14700 Info Setup logging for Topaz Video 1.7.2
2026-10-17 12-20-03.721 Thread: 14700 Info "InstallDir" :  "<TOPAZ_INSTALL_DIR>"
```
`<date> <time> Thread: <tid> <Level> <message>`;Level ∈ Debug/Info/Warning/Error。

### 4.2 关键标记(正则建议)

| 用途 | 模式(实测=本机验证过 / 社区=公开资料) | 备注 |
|---|---|---|
| 版本 | `Setup logging for Topaz Video ([0-9.]+)` | 实测 |
| 安装/模型路径 | `"InstallDir"` / `"ModelDir"` 行 | 实测 |
| 导出开始 | `Video Export Started (\{.*\})` | 社区;JSON 内含 models、`commands`(完整 neuroserver 命令行) |
| 命令行回显 | `Info ".*neuroserver.exe" QList\("--once"` | 社区 |
| hook 审计 | `\[slp-tune\]` / `\[SLP Lite\]` / `\[Topaz SLP override\]` | 自己实现可控 |
| 渲染进度(1.7.x) | **待实测**:含 `chunk`、`Frame range`、`load_cap`、阶段名(`VAE Encode`→`DiT Upscale`→`VAE Decode`) | 官方日志格式每代有变动,实现前务必用一次真实导出采样 |
| 完成 | `total processing time` | 社区 |

neuroserver 自身 stdout(GUI 模式会被 Topaz 收进日志;CLI 模式直接管道读取,本机实测):

```
INFO:local_model_service:model parameters: {...}          ← 最终生效参数(与审计交叉验证)
INFO:interface:{"status": "RUNNING", "frame": N, "progress": P, "message": ""}   ← 进度
single_shot_process status: ... / TopServingErrorCode.MODEL_INFERENCE_ERROR        ← 结束/错误
```

另有 `安装目录\neuroserver\logs\` 可作为次要数据源。

### 4.3 进度模型(ETA)

- 输入总帧数/帧率:从导出开始行或首帧行解析;
- 稳定均值 = 排除第 1 个 warm-up 分块与末尾短片后的 fps;
- 剩余时间 = 剩余帧 / 稳定均值;**不要**用全程均值(前段模型加载会严重拖低);
- 处理时长只计 VAE Encode 起,不含预处理/加载。

### 4.4 实现要点

- tail 时同时监控目录出现的新文件(导出过程中会滚动新日志);
- 只读打开(`FILE_SHARE_READ|WRITE`),不要锁文件;
- 解析器做成"行状态机",容忍未知行(升级不崩)。

## 7. 逆向评估(REA 路线)

**REA = `morluto/rea`(Reverse Engineer Anything)**,MIT 协议,MCP + CLI,`npx rea-agents@latest setup`。
- 原生二进制分析需 Hopper/Ghidra/IDA;**Ghidra 免费**(12.1.x + JDK 21);
- 还内置 JS/Electron、.NET、APK、网站等静态分析(无需逆向引擎)。

**但对这两个目标,Ghidra 路线的 ROI 很低**,因为:

| 目标 | 打包方式 | 正确管线 |
|---|---|---|
| SLP_Lite | PyInstaller **onedir**(`_internal\python313.dll` 可见) | `pyinstxtractor-ng` 一键抽出 `.pyc` → 反编译 |
| Topaz-SLP-Launcher | PyInstaller **onefile**(26MB) | 同上(先解包) |

反编译工具(Python 3.13):`pycdc`(Decompyle++)/ `pylingual` 在线版;读不动时用 `pycdas`/`dis` 看字节码。

**真正的价值差异**:
- hook 逻辑(最大价值):**已经是明文 Python**,无需任何逆向(见 §5);
- 监控解析/autotune 调度/cuDNN 管理:在 `.pyc` 里 → **pyinstxtractor 管线即可**;
- Fusion GPU 内核(cubin)/EXE 引导器:只有这部分才轮到 Ghidra/REA,且 GPU 字节码分析性价比极低(其 JSON 元数据已可读)。

**合规提示**:两者均为免费软件(MIT/自由分发)。个人研究学习其技术思路可以,但**不要整体搬运反编译代码、不要重新发布**,参考时注明来源。

## 附录 A. neuroserver CLI 参数(实测格式)

```
neuroserver.exe --once
  --input-path <in.mp4> --output-path <out.mp4>
  --start-frame-idx 0 --end-frame-idx <N>
  --max-gpu-mem 96
  --filters '[{"model":"slp-26","enhancement_strength":1.0,"softness":1}]'   # softness: 1/2/3
  --output-width <W> --output-height <H> --upscale-factor <F>
  --ffmpeg-encoding "<编码参数串>"                                            # 如 h264_nvenc constqp qp18
```
- 工作目录必须是 neuroserver 目录;`TOPAZ_MODEL_STORE=<模型库>`;非 N 卡/未激活会直接报错;
- 模型 ID:`slp-26`(星光 2.6)实测可用;`slp-25` 为 2.5。

## 附录 B. hook 最小实现清单

1. `sitecustomize.py` 放独立目录,`PYTHONPATH` 指过去;
2. 包装 `importlib.machinery.ExtensionFileLoader.exec_module`(或 meta-path finder);
3. `name.startswith("models.slp2")` 且契约属性齐全 → 才注入;
4. 逐参数 `setattr`,每个都 try/except 并记审计;
5. 审计:stdout(带固定前缀)+ 可选 JSONL 文件;
6. 绝不 import 除标准库以外的东西(neuroserver 环境里只有 torch 家族)。
