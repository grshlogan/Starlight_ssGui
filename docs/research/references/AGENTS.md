# 参考简报与证据附录 — 目录规则

本目录存放对**外部来源**的研究产出:简报记结论与适用边界,证据附录按来源逐条给出证据(钉在版本/提交上)。本文件定义目录规则,不替代产品章程、架构基础或 ADR。

## 规则

1. 简报只写:**结论、适用范围、不适用范围、与项目的接口点**;实现细节进附录或被引用文档。
2. 证据附录:每条结论指向具体来源(文件/行、命令、哈希、版本或提交);来源为闭源分析时注明工具版本与解包方法。
3. 简报与采纳分离:简报是研究材料,**不构成**架构事实;采纳必须走 [决策登记](../../decisions/AGENTS.md) 的 ADR 流程。
4. 命名:`<YYYY-MM-DD>-<slug>.md`(简报)/ `<YYYY-MM-DD>-<slug>-evidence.md`(附录);同一主题的简报与附录互相链接。
5. 不写原始日志全文、凭据、绝对路径;引用路径使用别名(见 `docs/START_HERE.md`)。
6. 来源登记与哈希在 [来源登记](../AGENTS.md) 与 `learn/` 索引中维护,本目录不重复。
