# 设计文档与资产 — 目录规则

本目录记录面向用户的交互/视觉设计约束、提案与资产索引。设计结论需任务授权后才能进入实现;本文件定义目录规则,不替代产品章程、架构基础或 ADR。

## 规则

1. 每份设计文档写明:问题、目标读者、范围与状态;`Proposed`、`planned` 与已验证结果分开。
2. 设计约束与产品范围冲突时,回链 [产品章程](../product/AGENTS.md);涉及公共契约、平台能力或取舍时,回链 [架构基础](../architecture/AGENTS.md) 或 [决策登记](../decisions/AGENTS.md)。
3. 设计文件、原型、截图等非文本资产,须可追溯到所属文档(资产放 `assets/` 并在文中登记);创建子目录时同样放置其 `AGENTS.md`,不留无主文件。
4. 设计评审只记结论与未决项;设计通过不等于实现、发布或产品验收。
5. 不以原型或视觉预览作为运行期证据;实际行为以 [工程验证策略](../engineering/AGENTS.md) 的入口为准。
